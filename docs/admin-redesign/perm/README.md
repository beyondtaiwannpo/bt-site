# 權限重新設計：後台截圖（2026-10-24，批 2）

`/admin/people/` 改成職級與指派之後的樣子。用 `admin/people/src/ui.js` 配假資料在 headless Chrome 畫的，不是真的登入後截的；人名、工作區都是假的。
`01` 到 `12` 是中文桌機 1280px，`13` 到 `16` 是英文版，`m1` 到 `m5` 是手機 390px（CDP 真的視寬模擬，`scrollWidth` 都等於 390，沒有左右可捲）。

| 檔 | 畫面 |
|---|---|
| 01 | 幹部名單，預設這一屆：職級、職位、在哪幾個工作區 |
| 02 | 歷屆全部：沒有帳號的人、校友、可能是同一個人、還沒用的校友碼 |
| 03 | 改一個人：職級四級、名字、這一屆的職位、team 標籤、工作區、刪除成員 |
| 04 | 刪除成員第二步：列出會刪掉的東西、名字打一次 |
| 05 | 沒有帳號的人：發校友碼、合併、刪除紀錄 |
| 06 | 加一筆過去的紀錄 |
| 07 | 工作區：左邊十四個（假資料六個）、右邊誰在裡面與等級、加一個人 |
| 08 | 屆別：每一屆人數、補過去的一屆、貼一整屆 |
| 09、10 | 結束這一屆第 2 步（誰留下，自己勾死）與第 3 步（打代號） |
| 11 | 貼一整屆的預覽 |
| 12 | 變動紀錄：指派、職級、刪人、搬過來的 |
