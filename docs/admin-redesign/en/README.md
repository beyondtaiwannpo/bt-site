# 後台英文版截圖（2026-10-19）

後台加了中英切換之後，每一個畫面用英文畫一次的樣子。
用 `ui.js` 配假資料在 headless Chrome 畫的，不是真的登入後截的；人名、表單名都是假的。
`01` 到 `33` 是後台桌機 1280px，`m1` 到 `m6` 是後台手機 390px（`m2` 是後台選單展開的樣子）。
第二批（頂欄、設定、登入頁、兩本護照、時間看板）的檔名有前綴：`settings-`、`app-`、`passport-`、`intern-passport-`、`availability-`，`-m` 是手機。
做法見 `docs/2026-10-19-後台中英切換.md`，說明見 README「後台的中英切換」。
截圖時順便量過側欄、按鈕、chip 有沒有被英文撐到溢出，沒有。
