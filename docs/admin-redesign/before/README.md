# 後台重做之前的畫面（2026-10-19）

這一夾是重做之前的後台長什麼樣。截圖 01 到 18 是用 Paul 的 Chrome 以 Co-President 帳號在正式站 `beyondtaiwannpo.com/admin/` 截的；19 到 25 是正式站沒有申請表、看不到的那幾個畫面，用 `admin/src/ui.js` 的純函式配假資料畫出來的（頂欄是示意，真的頂欄在 `shared/nav.js`）。

每一張旁邊兩句：這一頁要做什麼，為什麼看起來亂。

## 整體的問題（每一頁都有）

1. **三層導覽疊在一起**：頂欄「後台」、分組列（申請、對外、護照、人與權限）、每組裡面的分頁列。三層長得都是藥丸鈕，沒有層次，看不出哪一層是「我在哪」。
2. **分頁列的位置會跳**：資源分頁把標題放在分頁列上面，團隊頁把分頁列放在標題上面。同一組裡點一下，整排按鈕就上下移。
3. **頂欄捲動後會蓋住內容**：頂欄是黏住的（sticky），捲下去之後分組列和列表的第一行被蓋掉。
4. **首頁只是一張目錄卡**：登入後看到的是「四組，你進得去的是連結」加四個名詞，沒有任何「你今天要處理什麼」。
5. **每一頁都是一張 940px 寬的大卡**，所有內容塞在同一張卡裡：說明、提醒、表單、清單。沒有區塊的層次，所以長清單（33 格、25 人、24 個城市）會變成一條沒有盡頭的瀑布。
6. **提醒用同一種橘色框，什麼都講**：注意事項、狀態訊息、錯誤訊息、系統說明全部長一樣。
7. **按鈕三種樣式混用**：深藍實心、框線、底線文字，在同一列裡沒有主從。
8. **手機寬度沒有壞，但沒有設計**：分組列折成兩行、卡片內距太大、長標題跟徽章擠在一起。

## 沒有截到的

- Director 與一般幹部真的登入後的畫面（只有 Paul 的 Co-President 帳號）。19 那張是用假的身分畫的。
- 「開一份新的申請表」按下去是瀏覽器原生的 `prompt()` 對話框問名字。這件事本身就是一個發現：它會把整個分頁卡住，而且在手機上長得跟網站完全不搭。
- 載入中、資料庫休眠、「這一頁是給幹部用的」三個狀態（在 harness 裡有 `down.html`、`not-cadre.html`，沒截）。
