# source-command-bt-goal

Use this skill when the user asks to run the migrated source command `bt-goal`.

## Command Template

# /bt-goal：把 beyondtaiwannpo.com 做成一個真的好看的網站

> 為什麼不叫 `/goal`：Codex 有內建的 `/goal`（用法 `/goal <condition>`），
> 內建指令優先度高過專案自訂的，取同一個名字會被整個蓋掉，打下去只會看到
> 「No goal set」。2026-09-07 踩過一次。改名前先確認新名字沒有內建指令佔用。

**讀完先給計畫，不要直接開始寫程式。**

先讀 `docs/2026-09-07-官網視覺方向.md`。那是設計系統（色票、字體、版面、動態原則、
要避開的套路、舊守門怎麼處理）。這份講要做什麼與怎麼驗收，不重複那裡的內容。

視覺原型在 `docs/prototypes/2026-09-07-hero.html`，Paul 看過。開一次來看，那是基準線，不是天花板。

---

## Paul 的原話

> 「可以不要管 repo 守門，我要好看、動態、震撼。這是一個很 Free 的 project。
> 我要 BT website 真的很好看。」

所以標準不是「有做出來」，是**好看**。做完覺得只是「還行」，就是沒做完。

---

## 一個主張

BT 的 Primary Logo 是台灣島輪廓加箭頭環繞。那不是標誌，是這個組織的一句話：
**島，和繞著它的移動。**

首頁不是「放一張台灣的圖」，是把 logo 放大到整個螢幕並讓它活過來。
**這是全站唯一需要震撼的地方。其他每一段都要安靜，讓這一個畫面獨大。**

---

## 要做出來的四件事

### 1. 首頁：一整個螢幕的台灣

- 取代現在的主視覺照片（`6G9A0492`）。照片不要刪，往下移。
- 島要**巨大且切出畫面**。不要把台灣完整放進一個框裡，那會變成插圖。
  切出去它才是地形。
- 島上有光點，對應 BT 服務過的公立高中所在地。橘色為主，蒂芬妮綠與亮黃各一兩顆。
  光暈往外擴散後消失，錯開時間，不要一起閃。
- 環繞的軌跡線（logo 的箭頭）用 SVG 畫出來，捲動時比島轉得更慢。
- 開場只有**一個 timeline**：島出現、標題三行依序落下、副標、軌跡畫出來。
  不要每個 section 各自淡入，那是 AI 生成頁面最明顯的特徵。
- 台灣輪廓**已經是真實地理資料，不要再換**。來源與重算方式見 `scripts/taiwan/README.md`：
  g0v 2010 縣市邊界，抽出只用過一次的邊界線得到純海岸線，投影簡化成 370 點，
  含澎湖、蘭嶼、綠島。金門馬祖刻意排除（會撐爆版面）。
  要調整精細度就改 RDP 的 eps 重跑，**不要手改座標**。
- **H1 與 lead 文案一字不改。** 中英兩版都是 2026-09-02 定稿逐句對過的。

### 2. `/alumni/`：航線圖

Paul 的原話：「比如我是新竹人現在在休士頓，點一下我就會像飛機導航圖一樣飛到休士頓。」

- 新資料夾 `/alumni/`，一個 `index.html`。
- **不需登入，不接 Supabase，不讀 `profiles` 表。** 資料走 `alumni/community.json`。
- 島在左，目的地節點在右。點島上的高中，一條弧線畫過去，落點浮出城市與學校，
  下面出現那個人的卡片。
- 弧線用 SVG path 加 `stroke-dasharray` 畫，不要用地圖套件。
- **不要畫世界地圖。** 情緒重點是「他們走得很遠」，不是麥卡托投影。
  弧線加上一個有名字的落點，就是一張導航圖，而且比塞一張世界地圖乾淨得多。
- 反向要能用：從落點點回去看他從台灣哪裡出發。
  community 是雙向的，不是單向離開。
- 引言用 **Iansui 芫荽**。那是 Brand Book 列為 Primary、用途寫明「故事分享與引言」
  但前端從來沒用過的繁中手寫體。**這是整個網站最有記憶點的一個決定。**

### 3. 頂部 menu bar

- 現在 `<header>` 只有一顆登入按鈕。加一條真的導覽列。
- **跟 `shared/nav.js` 是兩回事。** `nav.js` 的 `FEATURES` 是登入後功能清單的唯一來源。
  不要改它，不要把對外項目加進去，混在一起會讓沒登入的人看到登入後才有的功能。
- 項目：關於我們、我們做什麼、Alumni、加入我們、中英切換、登入。
  **Paul 說空的先放著沒關係。**
- sticky，捲動時背景毛玻璃。手機收成漢堡選單。
- 中英維持同一頁兩個區塊（zh 加 `.en`），不要拆成兩個網址。

### 4. 其餘五段

首頁六段結構與文案不動，只換視覺與版面。靠左對齊、不對稱、大留白。
「數字」那一段做數字遞增，那是 community 規模的直接證據，值得一個動畫。
其他四段安靜就好。

## 放開了什麼，沒放開什麼

完整對照表在 `docs/2026-09-07-官網視覺方向.md`。摘要：

**放開**：三色限制（改用 Brand Book 七色）、兩字體限制（改用四種，都在 Brand Book 五種內）、
不載中文字體、深藍不可大面積、不從 CDN 載東西。

**沒放開**（動到要先問 Paul）：
- **零 build step。** GSAP 從 CDN 載就夠，GitHub Pages 照舊從 `main` 根目錄發布。
  加打包工具就要改成 GitHub Actions 部署，那是另一個決定。
- **`shared/` 保持極小。** 地圖與航線的程式不准放進去，依賴方向只能往下。
- **logo 不可改色、拉伸、旋轉、調透明度。**
- **首頁六段中英文案一字不改。**
- **公開頁不可加新照片**，除非確認拍攝同意條款涵蓋。
- **`/passport/` 的隱私界線一律不動。** 心得與照片只有本人看得到。

`check.sh` 的三色與兩字體掃描要**重寫**成新色票與新字體白名單，**不是刪掉**。
守門還是要有，只是守的東西換了。

## 交接得動（這仍然是北極星）

放開守門不等於放棄「明年一位沒寫過程式的新任幹部能自己接手」。
互動地圖是這個 repo 最複雜的前端，所以它必須被關起來：

1. **資料與動畫分離。** 人名、學校、城市、座標全部在 `alumni/community.json`。
   換屆的人只改 JSON，永遠不碰動畫程式。JSON 開頭放 `_readme` 欄位寫格式（JSON 不能寫註解）。
2. **加一位 alumni 的成本必須是「在 JSON 加一個物件」**，不是改三個檔案。
3. **每個新檔案開頭寫一段給下一個人的話**：這支在做什麼、改什麼要小心、為什麼這樣做。
   照 `shared/brand.css` 開頭那個風格，那是這個 repo 的文件標準。

## 搭配 Codex 內建的 `/goal` 用

內建 `/goal <condition>` 會設一個停止條件，Codex 每次想結束回合之前先檢查條件達成沒有，
沒達成就自己繼續做。`/goal clear` 取消。發生無法恢復的錯誤時它會自動清掉條件並要你重下。

**用法**：先打 `/bt-goal` 把規格讀進來，再打 `/goal` 加下面對應那一批的條件。

### 什麼時候可以用，什麼時候不行

| 批次 | 能不能自動跑 | 為什麼 |
|---|---|---|
| 批 1 設計系統落地 | **可以** | 每一項都是機器自己驗證得了的（檔案內容、`check.sh`、`git diff`） |
| 批 2 台灣 hero | **不行** | 這一批的成敗是美感，Paul 一定要看過。條件寫「好看」等於沒有條件 |
| 批 3 alumni 航線圖 | **不行** | 同上，而且牽涉互動手感 |
| 批 4 SRI 與效能 | **可以** | 全部是可量測的 |

**通則**：條件必須是 Codex 自己跑得出真假的。凡是需要人的眼睛判斷的，就不要交給 `/goal`。

### 批 1 的條件（可直接貼）

```
批 1 完成：shared/brand.css 換成 Brand Book 七色四字體、check.sh 的三色與兩字體掃描改成新白名單（不是刪掉）且 ./check.sh 全綠、index.html 有 sticky 的對外 menu bar 且完全沒動 shared/nav.js、六段中英文案的 git diff 為零、首頁版面與字級照 docs/2026-09-07-官網視覺方向.md 重排、prefers-reduced-motion 下沒有任何東西在動、375px 寬可用、鍵盤 Tab 走得完、README 或 docs 已更新並 commit。每一項都要實際跑過或看過才算，不能只是「應該有」。任何一項做不到就停下來說明，不要跳過也不要放寬標準。
```

### 批 4 的條件（可直接貼）

```
批 4 完成：GSAP 與 Google Fonts 的 script 與 link 都有正確的 integrity 與 crossorigin（雜湊要實際算過並實測頁面仍正常載入）、中文字體有 unicode-range subset 與 font-display:swap、privacy/index.html 的第三方清單補上 cdnjs、用 Lighthouse 或同等工具實測首頁效能並把數字寫進 docs、./check.sh 全綠、已 commit。每一項都要有實測數字，不能只是設定完就算。
```

### 注意

- `/goal` 會讓它一直做下去，權限提示會擋住流程。開始前先用 shift+tab 切到自動接受編輯的模式，
  或先確認 `.Codex/settings.local.json` 的權限設定夠用。
- **「停下來問 Paul」那一節仍然有效。** 條件達成不代表可以跳過該問的事。
  碰到要問的就停，那不算失敗。
